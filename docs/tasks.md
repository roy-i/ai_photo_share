## 3. 登録・ログイン・ログアウト

- [ ] 表示名・一意なユーザー名・一意なメール・パスワード確認で登録できる。
- [ ] メール形式・文字数・重複・パスワード不一致を表示し、入力を直せる。
- [ ] パスワードをハッシュ化し、登録成功後にログインできる。
- [ ] メールとパスワードでログインし、POSTでログアウトできる。
- [ ] 24時間後に再ログインが必要になり、期限切れ後の変更操作が拒否される。
- [ ] 未ログイン時の保護された操作と、不正なCSRFトークンが拒否される。

完成条件: 採用パッケージで通常の認証が動き、入力・期限・ログアウト・アクセス制御を確認できる。

## 4. 写真投稿・一覧

- [ ] 画像1枚と任意の200文字以内のキャプションを投稿できる。
- [ ] JPEG・PNG・WebP、10MiB以内、画像内容を検証し、保存時にメタデータを除去する。
- [ ] 不正な画像や容量・文字数超過の理由を表示し、入力を修正できる。
- [ ] 未ログインでも投稿を新しい順に見られ、写真を拡大できる。
- [ ] 1ページ12件の表示と、投稿がない場合の案内を確認する。
- [ ] 再起動後も投稿が残り、再読み込みで投稿が重複しない。

完成条件: 実ブラウザで写真を選択・投稿・表示し、再起動後も確認できる。

## 5. 本人による編集・削除

- [ ] 本人だけがキャプションを編集できる。写真は差し替えない。
- [ ] 確認後に本人の投稿を削除し、写真・いいね・コメントも削除できる。
- [ ] 他人の操作は403、存在しない対象は404、POST専用URLへのGETは405になる。

完成条件: 所有者制御と関連データの削除、失敗時の状態を確認できる。削除の確認には、明示的に用意した検証用データを使う。
