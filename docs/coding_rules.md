# コーディングルール

- 初学者向けに小さなファイル構成と分かりやすい関数名を使う。
- app.pyは画面と処理、config.pyは設定、database.pyは接続、models.pyはDB構造。
- HTMLはtemplates/、CSSはstatic/。複雑なフロントエンドや外部CDNは使わない。
- フォームの値はサーバーでも検証する。所有者チェックとCSRFチェックを省略しない。
- Jinjaの自動エスケープを保ち、投稿文にsafeを使わない。
- 画像名はUUIDで生成し、元のファイル名を保存パスに使わない。
- 画像内容・容量を検証する。Pillowは画像検証・向き補正・メタデータ除去に使う。
- 写真・DB・キー・仮想環境はGitに入れない。
- unittestで利用者の操作と失敗時、実ブラウザでPC・スマホ幅を確認する。
