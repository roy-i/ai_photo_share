# 画面設計

## 設計方針

Flaskのテンプレートで画面を表示する。登録とログイン、投稿と編集は、それぞれ共通のテンプレートを使い、ファイル数を抑える。

写真の拡大、削除の確認、テーマ切り替えは画面内で行い、専用ページを増やさない。

## 1. ホーム・投稿一覧

- **目的**：友人の写真を新しい順に見る。
- **ログイン**：不要。
- **URL・メソッド**：`GET /`
- **テンプレート**：`index.html`
- **表示内容**：写真、表示名、キャプション、投稿日時。追加機能として、いいね件数とコメント。
- **操作・遷移**：登録、ログイン、写真投稿、本人のキャプション編集へ移動できる。

未ログインの場合、投稿・いいね・コメントの操作からログイン画面へ案内する。本人の投稿だけに編集・削除の操作を表示する。

写真を選ぶと拡大表示し、閉じると一覧に戻る。削除は一覧内で確認してから実行する。投稿がない場合は、最初の投稿を案内する。

ページを分ける場合は `/?page=2` のように指定し、1ページ12件を表示する。

## 2. ユーザー登録

- **目的**：写真を投稿するためのアカウントを作る。
- **ログイン**：不要。ログイン済みの場合はホームへ戻す。
- **URL・メソッド**：`GET /register`、`POST /register`
- **テンプレート**：`auth.html`。登録用の表示に切り替える。
- **入力項目**：表示名、メールアドレス、パスワード、確認用パスワード。
- **画面遷移**：登録成功後はログイン状態になり、ホームへ移動する。

入力エラーやメールアドレスの重複は同じ画面に表示する。表示名とメールアドレスは保持し、パスワードは再入力する。ログイン画面へのリンクも設ける。

## 3. ログイン

- **目的**：登録済みのアカウントで利用する。
- **ログイン**：不要。ログイン済みの場合はホームへ戻す。
- **URL・メソッド**：`GET /login`、`POST /login`
- **テンプレート**：`auth.html`。ログイン用の表示に切り替える。
- **入力項目**：メールアドレス、パスワード。
- **画面遷移**：成功後はホームへ移動する。

失敗時は同じ画面に理由を表示し、メールアドレスを保持する。ユーザー登録へのリンクも設ける。

## 4. 写真投稿

- **目的**：写真1枚とキャプションを投稿する。
- **ログイン**：必要。
- **URL・メソッド**：`GET /posts/new`、`POST /posts/new`
- **テンプレート**：`post_form.html`。新規投稿用の表示に切り替える。
- **入力項目**：写真1枚、任意のキャプション。
- **画面遷移**：投稿成功後はホームへ移動する。キャンセルもホームへ戻る。

選んだ写真をプレビューする。写真はJPEG・PNG・WebP、10MB以内、キャプションは200文字以内とする。エラー時は同じ画面に理由を表示し、キャプションを保持する。写真は選び直す。

## 5. キャプション編集

- **目的**：自分の投稿のキャプションを修正する。
- **ログイン**：必要。投稿した本人のみ利用できる。
- **URL・メソッド**：`GET /posts/<int:post_id>/edit`、`POST /posts/<int:post_id>/edit`
- **テンプレート**：`post_form.html`。編集用の表示に切り替える。
- **入力項目**：キャプション。写真は確認用に表示し、変更できない。
- **画面遷移**：保存成功後、またはキャンセル時にホームへ戻る。

文字数超過の場合は、入力したキャプションを残して同じ画面に理由を表示する。

## 6. エラー表示

- **目的**：操作できなかった理由と、戻り先を伝える。
- **ログイン**：不要。
- **URL**：専用URLは作らず、エラーが起きたURLで表示する。
- **HTTPメソッド**：原因となったリクエストのメソッド。
- **テンプレート**：`error.html`
- **対象**：送信内容の問題・画面の有効期限切れ（400）、権限不足（403）、対象なし（404）、送信容量超過（413）。
- **画面遷移**：ホームへ戻れる。容量超過の場合は写真投稿画面へ戻る案内も表示する。

通常の入力間違いは、専用エラー画面ではなく元のフォーム内に表示する。

## 共通表示と追加機能

`base.html` に共通のナビゲーション、通知、ライト・ダーク切り替えを置く。テーマの選択はブラウザ内に保存し、専用URLは作らない。

いいねとコメントは、基本機能の完成後に一覧内へ追加する。ログアウトにも専用画面を作らない。

## 主な画面遷移

- ホーム → ユーザー登録 → 登録成功 → ホーム
- ホーム → ログイン → ログイン成功 → ホーム
- ホーム → 写真投稿 → 投稿成功 → ホーム
- ホーム → 本人のキャプション編集 → 保存成功 → ホーム
- ホーム → 投稿削除の確認 → 削除成功 → ホーム
- ホーム → ログアウト → 未ログインのホーム
- ホーム → 写真の拡大 → 閉じる → ホーム
