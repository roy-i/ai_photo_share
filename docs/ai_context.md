# AIに渡すアプリの前提

友人同士で旅行や日常の写真を見せ合う写真共有アプリ「memento」を作る。初学者が学べる構成で、まず自分のMac上で動かす。

## 詳細を確認する資料

- 全体の要件: `docs/requirements.md`
- 画面・画面遷移: `docs/screens.md`
- URL・HTTPメソッド・アクセス制御: `docs/routes.md`
- テーブル・制約・関係: `docs/database.md`
- 作業順序・完成条件・進捗: `docs/tasks.md`
- 実装時のルール: `docs/coding_rules.md`

このファイルは概要であり、詳細は各設計資料を読む。資料と実装に違いがあれば、合意した仕様を確認し、作業中の実装を完成済みと扱わない。

## 技術・実行環境

- Flask・Peewee・SQLiteを使用し、この技術の枠は変更しない。Pythonは `.venv` 内で実行する。
- 採用パッケージ: Flask、peewee、Flask-Login、Flask-Session、cachelib、Flask-WTF、email-validator、Pillow、python-dotenv。
- ログイン操作はFlask-Login、サーバー側のセッション保存はFlask-SessionとCacheLibのファイル保存で扱う。セッションは `instance/sessions/` に保存し、ログインから24時間で期限切れにする。
- フォームとCSRFはFlask-WTF、メール形式はemail-validator、画像処理はPillowで扱う。秘密鍵は環境変数 `PHOTO_SHARE_SECRET_KEY` から読む。開発時はpython-dotenvで `.env` を読み込む。
- DBは `instance/photo_share.sqlite3`、ユーザー投稿画像は直下の `uploads/`、CSS・JSは `static/`、HTMLは `templates/` に置く。
- 自動テストは現在のunittestを使う。pytestは必要になった場合に追加できる候補であり、必須ではない。

## カリキュラムの最小版

07章では、設定読み込み・DB接続を備え、ログインなしでトップページに「写真共有アプリ」と表示する。認証・写真投稿などは後の段階で追加する。既存の実装がある場合は、その確認のために削除・作り直しをしない。

## 必須機能と制限

- 一覧と写真の閲覧はログイン不要。投稿を新しい順に表示し、写真を拡大できる。
- 登録は表示名・ユーザー名・メールアドレス・パスワード・確認用パスワード。ログインはメールアドレスとパスワード。登録成功後もログイン状態になる。
- 表示名は1〜30文字・重複可。ユーザー名は半角英数字と `_` の3〜30文字・一意。メールは254文字以内・一意。ユーザー名とメールは空白除去・小文字化する。
- パスワードは8〜128文字。ハッシュ化して保存し、他の利用者にメールやハッシュを表示しない。
- 写真は1投稿1枚、JPEG・PNG・WebP、10MiBまで（画面では10MB）。キャプションは任意・200文字以内。
- ログインした人が投稿できる。本人のみキャプション編集・投稿削除ができ、写真は差し替えない。
- 投稿削除時は写真ファイルと関連するいいね・コメントも削除する。

## 基本機能の確認後に追加する機能

- いいねはログイン必須、1人1投稿1件、自分の投稿も可、取り消し可能。件数を一覧に表示する。
- コメントはログイン必須、1〜300文字、空白だけは不可。同じ投稿に複数回書ける。閲覧は公開、本人のみ削除可能、編集は作らない。

## デザイン・デモ・後続制作

Instagramを参考に写真を中心にしたUIを作る。ライト・ダークの選択をブラウザに保存し、PC・スマホと動きを減らす設定に対応する。豊富な動きは操作を妨げない範囲で使う。

自然な実写のサンプル投稿を数件用意し、サンプルと明記する。既存データを保護し、追加処理を繰り返しても重複させない。画像生成が必要な場合はChatGPTを使う。「デモでログイン」はローカル版のみで有効にし、入力なしで固定のハル（デモ）として操作できるようにする。

機能が揃った後にOpusへデザイン刷新・最終レビューを依頼する。アプリ完成後に段位グラフ紹介のようなPVをOpusへ依頼し、尺・音声・出力形式は制作時に確認する。

## 対象外と作業の境界

検索、フォロー、招待、ストーリー、DM、複数写真、動画投稿、メール確認、パスワード再設定、Googleログイン、インターネット公開は今回作らない。カリキュラム順に小さく進め、現在の段階は `docs/tasks.md` を確認する。コミット・push・公開は本人が依頼した範囲だけ行う。
