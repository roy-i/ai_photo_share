# 写真共有アプリの要件

友人同士で旅行や日常の写真を見せ合う。まず自分のMacだけで動かす。

## 承認済みの仕様
- Flask + Peewee + SQLite。
- 一覧と写真とコメントの閲覧はログイン不要。新しい投稿から表示する。
- メールアドレスとパスワードで登録・ログイン・ログアウト。
- ログインした人は写真1枚と任意のキャプションを投稿できる。
- 投稿者のみキャプション編集・投稿削除。写真の差し替えは投稿し直す。
- いいねはログイン必須。1人1投稿1件、取り消し可能。件数を一覧表示。
- コメントはログイン必須で投稿でき、本人のみ削除可能。
- 投稿削除時は写真、関連するいいね・コメントも削除。

## 初期設定
- 写真: JPEG・PNG・WebP、1枚10MiB（画面では10MBと表記）まで。uploads/に保存。
- キャプション: 任意、200文字以内。コメント: 空白だけは不可、300文字以内。
- 表示名: 1〜30文字。メールアドレス: 254文字以内・一意、前後の空白を除去して小文字で保存。
- パスワード: 8〜128文字、確認入力あり。ハッシュ化して保存する。
- DBとセッション署名キーはinstance/に保存し、再起動後も維持する。
- 写真は画像内容を検証して向きを補正し、位置情報などのメタデータを保存しない。

## 対象外
検索、フォロー、招待、メール送信、Googleログイン、インターネット公開。

## 最新のユーザー指定
メールアドレスとパスワードでログインする。Instagramを参考に写真中心のUIとし、モーショングラフィックス・アニメーションを豊富に使う。スパルタキャンプで見せられるデザイン完成度を目指す。スマホと動きを減らす設定にも対応する。

ライト・ダークを切替可能にする。完成時はサンプル投稿を数件表示する。機能完成後にOpusへデザイン刷新・レビューを依頼し、完成後に段位グラフ紹介のようなPV制作を依頼する。画像生成が必要な場合はChatGPTを使う。
